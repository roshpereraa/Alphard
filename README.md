# Alphard

**The solitary one.** Alphard is an independent studio site for immersive web, real-time and spatial work.

## The meaning

Alphard (α Hydrae) is the brightest star in Hydra, the largest constellation in the sky. Its name comes from the Arabic *al-fard*, "the solitary one", because it sits in a dark patch of sky with no bright neighbours. Its older name, *Cor Hydrae*, means "the heart of the serpent."

The brand is built on four ideas from the star:

- **Solitary.** An independent studio with no holding group and no account layers.
- **Luminous.** An orange giant hundreds of times brighter than the Sun, so the ambition is large.
- **Cor Hydrae.** Every project has a clear heart, and everything else is built around it.
- **Light that travels.** Alphard's light takes about 177 years to reach us, so the work should last.
